# Сайт Ярославской церкви АСД

Сайт на **Node.js + [Astro](https://astro.build)**. На выходе — статический сайт (папка `dist/`). Публикуется на GitHub Pages и сам обновляется по расписанию.

## Как запустить у себя

Нужен Node.js 20 или новее.

```bash
npm install        # один раз
npm run dev        # сайт откроется на http://localhost:4321
```

| Команда | Что делает |
|---|---|
| `npm run update:news` | Обновляет новости (текст из Telegram, фото со стены ВК) |
| `npm run update:stream` | Обновляет видео трансляции (последнее видео с Rutube) |
| `npm run update` | Обе команды сразу |
| `npm run build` | Собирает готовый сайт в `dist/` |
| `npm run preview` | Показывает собранный сайт из `dist/` |

## Что обновляется само

### Новости — раз в день

`scripts/update-news.mjs`:

1. Читает публичную страницу канала **t.me/s/yachurch** и берёт текст постов.
2. **Новость — это пост со ссылкой на альбом ВК.** Если ссылку выложили отдельным постом сразу после отчёта, она приклеивается к отчёту.
3. Находит такой же пост на стене группы ВК и скачивает **прикреплённые к нему фото** в `public/img/news/<id>/`.
4. Оформляет текст: заголовок, абзацы, стих из Библии — цитатой, ссылка на альбом — кнопкой «Весь альбом во ВКонтакте».

Результат — `src/data/news.json`.

**Ключ ВК.** Нужен только «Сервисный ключ доступа» приложения ВК (бесплатно: https://id.vk.com/about/business/go → создать приложение → скопировать сервисный ключ). Защищённый ключ и ID приложения не нужны. Локально ключ лежит в `.env` (`VK_TOKEN=...`), на GitHub — в секретах репозитория. С сервисным ключом ВК не отдаёт сами альбомы (`photos.get`), поэтому фото берутся из поста на стене — это те же фото, что в посте.

### Трансляция — по субботам каждые 10 минут

`scripts/update-stream.mjs` берёт с канала Rutube идущий эфир, а если эфира нет — последнее видео, и записывает в `src/data/stream.json`. Его показывают блоки «Богослужение из дома» на главной и на `/online`. Во время эфира появляется отметка «Сейчас в эфире».

## Публикация на GitHub Pages (бесплатно)

Всё описано в `.github/workflows/site.yml`:

- каждый день в 6:00 по Москве — новости + трансляция → сборка → публикация;
- по субботам с 9:00 до 13:00 — каждые 10 минут проверка трансляции; сайт пересобирается, только если появилось новое видео;
- при каждом изменении кода в ветке `main` — сборка и публикация;
- обновлённые новости и фото бот сохраняет в репозиторий, поэтому они не скачиваются заново.

Сайт: **https://xrustick.github.io/YAR.CHURCH/** (репозиторий [XrusticK/YAR.CHURCH](https://github.com/XrusticK/YAR.CHURCH)).

Настройки репозитория:

1. **Settings → Pages → Source: GitHub Actions** (уже включено).
2. **Settings → Secrets and variables → Actions → New repository secret:** имя `VK_TOKEN`, значение — сервисный ключ ВК. Без него новости собираются с одним фото из Telegram.
3. Запустить вручную: **Actions → «Обновление и публикация сайта» → Run workflow**.

Сайт работает и в подпапке репозитория, и на своём домене: адрес и базовый путь сборка берёт из настроек Pages сама. Свой домен (например, `yar.church`) подключается в **Settings → Pages → Custom domain**.
